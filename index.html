BENCHMARK BUDDY

Benchmark Buddy for Orangetheory Coaches

Benchmark Buddy is a Chrome extension for Challenge Tracker. It shows class times on Personal Record Breakers, PR rates per class, and each member's PRs and target speeds on class rosters. Coaches can send a class sheet to their phone with a QR code.

An independent tool made by an Orangetheory franchisee. Not made, endorsed, or supported by Orangetheory Fitness.
