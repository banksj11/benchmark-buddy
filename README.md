# Benchmark Buddy

Website for the Benchmark Buddy Chrome extension (Orangetheory Challenge Tracker overlay), hosted on GitHub Pages.

- `v/` is the phone viewer. Coaches scan a QR code in Challenge Tracker and the class sheet opens here. The data travels in the link after `#`, so it is never sent to or stored on this site.
- `privacy/` is the privacy policy used for the Chrome Web Store listing.
- `index.html` is a short landing page.

No member data is stored in this repository.
