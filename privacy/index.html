BENCHMARK BUDDY

Privacy Policy

Last updated November 6, 2026

Benchmark Buddy for Orangetheory Coaches ("Benchmark Buddy") is a Chrome extension built by an independent developer for coaches and staff at Orangetheory Fitness studios. It adds information to the Orangetheory Challenge Tracker website (ct.orangetheory.com): class times on the Personal Record Breakers screen, PR rates per class, and each member's PRs and target speeds on class rosters.

Benchmark Buddy is an independent tool. It is not made, endorsed, or supported by Orangetheory Fitness.

Who can use it

Benchmark Buddy only works on ct.orangetheory.com while a staff member is already signed in to Challenge Tracker. It does not add any access. It only rearranges and calculates from information that the signed-in staff member can already see in Challenge Tracker.

What it reads

  • The Challenge Tracker data the page already loads: member first name and last initial, benchmark results, PR history, class times, and the challenge of the day.
  • The studio's class schedule from Orangetheory's own systems: class times, class names, headcounts, and coach names.

All requests go to Orangetheory's own servers, use the staff member's existing sign-in, and are read-only. Benchmark Buddy never creates, edits, or deletes anything in Challenge Tracker.

What it stores

  • A short summary of recent class schedules (class time, class name, headcount, coach name) in the browser's local storage on that computer, so PR rates can be shown later. Only the most recent 14 days are kept.
  • No member names, results, emails, or sign-in information are saved by Benchmark Buddy.

What it sends, and to whom

Benchmark Buddy does not send data to the developer or to any third party. There are no analytics, no tracking, no ads, and no cookies.

Send to phone (QR code). When a staff member chooses to show a QR code, the class sheet (member first name and last initial, PR times, and target speeds) is packed into the QR code itself. The link opens a simple viewer page on GitHub Pages. The class data sits in the part of the link after the # symbol, which web browsers do not send to the server. The viewer page reads it on the phone and displays it. Nothing is uploaded or saved. GitHub may keep standard web server logs (such as IP address and time of visit) for the viewer page, but those logs never include the class data.

Permissions

Benchmark Buddy asks for access only to ct.orangetheory.com. It does not request access to other websites, browsing history, tabs, or personal accounts.
